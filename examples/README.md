# Examples

This directory contains lightweight case artifacts for the RhoAgent pipeline. We have take the design of twister as one typical example.

- **`agent_dialog_history.json`**: a case of conversation / run history, including the agent's planning, tool calls, and critic feedback records.
- **`results.csv`**: a case of design output table produced by the pipeline (candidate designs and their evaluation metrics).
- **`results_filtered.csv`**: a case of design results after filtered.
